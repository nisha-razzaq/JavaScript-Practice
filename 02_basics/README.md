## ✨ Overview

This folder contains beginner-friendly examples that help you understand two of the most important data structures in JavaScript: **arrays** and **objects**.  
It also includes examples of common methods and techniques used to work with them in real projects.

---

## 📚 Topics Covered

### Arrays
- Creating arrays
- Accessing and updating elements
- Array methods
- Flattening arrays
- Converting values to arrays
- Sorting, reversing, pushing, popping, shifting, and unshifting

### Objects
- Creating objects
- Accessing object properties
- Nested objects
- Objects inside objects
- Object methods
- Object copying
- Object merging
- Destructuring
- Checking property existence

## 🎯 What You’ll Learn

By exploring this folder, you’ll learn how to:

- Work with array values and indexes
- Use built-in array methods
- Flatten nested arrays
- Convert strings and other values into arrays
- Create and manipulate objects
- Use nested object structures
- Copy and merge objects
- Destructure object values into variables
- Check whether a property exists in an object

## ▶️ How to Use

1. Open the folder in your code editor.
2. Read the comments in each JavaScript file.
3. Run the files using Node.js or your browser console.
4. Modify the examples and observe how the output changes.
