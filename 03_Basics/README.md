
# 03_Basics

---

## ✨ Overview

This folder contains examples that help you understand how functions work in JavaScript, including different ways to write and use them.  
It also introduces **arrow functions** and **IIFEs (Immediately Invoked Function Expressions)**, which are important concepts for writing cleaner and more modular code.

---

## 📚 Topics Covered

### Functions
- Function declarations
- Function expressions
- Passing arguments
- Returning values

### Arrow Functions
- Basic arrow function syntax
- Concise return syntax
- Returning objects from arrow functions

### IIFEs
- Named IIFE
- Anonymous IIFE
- Immediate execution patterns

---

## 📁 Files Included

- `01_functions.js`
- `02_arrow.js`
- `03_IIFI.js`

---

## 🎯 What You’ll Learn

By working through this folder, you’ll learn how to:

- Define and call functions
- Pass values into functions
- Return results from functions
- Write arrow functions in different forms
- Return objects from arrow functions
- Use IIFEs for immediate execution and scope isolation

---

## ▶️ How to Use

1. Open the folder in your code editor.
2. Read the examples in each `.js` file.
3. Run the code using Node.js or in the browser console.
4. Try rewriting the functions in different ways to strengthen your understanding.
