## ✨ Overview

This folder contains examples that explain how JavaScript makes decisions using conditional logic.  
It is useful for learning how to control the flow of your code with `if`, `else`, nested conditions, and strict comparisons.

---

## 📚 Topics Covered

- Conditional statements
- `if` / `else`
- Nested conditions
- Equality vs strict equality
- Comparison operators
- Decision-making logic

---

## 📁 Files Included

- `01.js`
- `README.md`

---

## 🎯 What You’ll Learn

By working through this folder, you’ll learn how to:

- Write and use `if` statements
- Understand when code blocks run
- Use strict comparison with `===`
- Build nested decision logic
- Control program flow based on conditions

---

## ▶️ How to Use

1. Open the folder in your code editor.
2. Read the comments inside `01.js`.
3. Run the file using Node.js or in the browser console.
4. Modify the conditions and observe the output.
