## ✨ Overview

**JavaScript Practice** is a collection of small learning exercises and code examples focused on building a strong foundation in JavaScript.

This repository covers core JavaScript concepts through simple, well-organized practice files, including:

- variables and data types
- type conversion
- comparisons
- memory concepts
- strings
- arrays
- objects
- functions
- arrow functions
- IIFEs
- control flow
- numbers, math, and dates

It is designed for learning, revising, and experimenting with JavaScript fundamentals.
