## ✨ Overview

This folder contains simple JavaScript examples focused on building a strong foundation in the language.  
It is ideal for learning the most important basics before moving on to arrays, objects, functions, and more advanced topics.

---

## 📚 Topics Covered

- Variables
- Data types
- Type conversion
- Comparisons
- Memory concepts
- Strings
- Numbers and math
- Dates and time

- `10_dates&time.js`

---

## 🎯 What You’ll Learn

By working through this folder, you’ll learn how to:

- Declare and use variables
- Understand primitive data types
- Convert between strings, numbers, and booleans
- Compare values using equality and strict equality
- Understand basic memory behavior in JavaScript
- Work with strings and string methods
- Use math utilities and number methods
- Create and format dates

---

## ▶️ How to Use

1. Open this folder in your code editor.
2. Read the comments inside each `.js` file.
3. Run the code using Node.js or in the browser console.
4. Experiment by changing values and observing the output.
